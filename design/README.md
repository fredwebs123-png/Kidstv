# Kidstv designs

The mockups for the Sony Google TV home, one file per screen (1920x1080):

| File | Screen |
|---|---|
| `mockups/Main.dc.html` | Home for Blake, clock in the middle |
| `mockups/Lucy.dc.html` | Home for Lucy |
| `mockups/Sora.dc.html` | Little mode for Sora: big pictures only |
| `mockups/Profiles.dc.html` | Who's watching? |
| `mockups/Bedtime.dc.html` | The Goodnight screen |
| `mockups/Pin.dc.html` | Grown-ups PIN |
| `mockups/MakePin.dc.html` | The first time: make the PIN |
| `mockups/Grownups.dc.html` | The grown-ups home |
| `mockups/Controls.dc.html` | Grown-ups controls (bedtime) |

The live, editable copy is the Kidstv mockups canvas on claude.ai; these are its source files,
kept here so the designs are versioned with the code. They open on that canvas (they need its
`support.js`), not straight in a browser. Show titles and posters are placeholders.
